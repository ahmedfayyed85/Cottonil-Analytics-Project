# Cottonil | Business Intelligence Dashboard

## Project Overview
An end-to-end Business Intelligence project developed using Microsoft Power BI to analyze retail business performance and transform raw data into actionable insights.

## Dashboard Pages

1. Executive Overview
2. Inventory & Stock Analysis
3. Returns & Store Analysis
4. Supplier Analysis
5. Sales Performance Analysis
6. Discounts & Promotions Analysis
7. Sales Forecasting

## Tools & Technologies
- Microsoft Power BI
- DAX
- Power Query
- Data Modeling
- Power BI Project (PBIP)
- Business Intelligence & Data Visualization

## Key Features
- Interactive dashboards and KPI cards.
- Sales and revenue performance analysis.
- Inventory and product analysis.
- Supplier payments, invoices, and outstanding balances.
- Returns and discount analysis.
- Month-over-Month performance comparisons where supported by the available data.
- Sales forecasting and trend analysis.

## Project Structure
- `.pbip` — Power BI project entry point.
- `.Report` — Report pages, visuals, themes, and layout definitions.
- `.SemanticModel` — Semantic model, DAX measures, relationships, and metadata.

## Note
This project is intended for portfolio and educational purposes. Any sample or anonymized data should be identified accordingly.
